# Skyfight — קרב שמיים

קרב מטוסים אונליין בדפדפן, כולם נגד כולם. נכנסים בלי הרשמה, בוחרים שם ומטוס, ומשוגרים לשמיים. כל הפלה נותנת XP וזהב. ה־XP מעלה רמות, והזהב קונה מטוסים ושדרוגים שנפתחים ברמות. שומרים את ההתקדמות עם שם משתמש וסיסמה וממשיכים מכל מכשיר.

## מה יש

- **5 מטוסים משבעים שנות תעופה:** סער (לוחם בוכנה, 1944), ברק (סילון כנף משוכה, 1953), רעם (דו־מנועי כבד, 1976), כפיר (כנף משולשת, 1975), אדיר (חמקן, 2016). כל אחד נפתח ברמה אחרת ונקנה בזהב.
- **נשק:** מקלעים או תותחים לפי התקופה, טילים מונחים (רקטות במטוס הבוכנה), ונורים שמטעים טיל שננעל עליך.
- **המפה:** עיר נמל עם מגדלים ורחובות, גשר תלוי מעל המפרץ שאפשר לטוס מתחתיו, ים עם איים וספינות, והרים במזרח. בניינים והגשר מוצקים: מי שנכנס בהם מתרסק.
- **4 שדרוגים, 5 דרגות לכל אחד:** מנוע, שריון, תותחים וטילים. השדרוגים עוברים איתך לכל מטוס.
- **30 רמות:** הראשונות לוקחות דקות, האחרונות שעות.
- **בוטים:** כשהשמיים ריקים, בוטים ממלאים אותם. כששחקנים נכנסים, הבוטים מפנים מקום.
- **שליטה:** בטלפון יש ג'ויסטיק וכפתורים, במחשב חצים או WASD, רווח, Shift ו־E.

## הרצה מקומית

```bash
npm install
npm run dev          # http://localhost:2567
```

## בדיקות

```bash
npm run qa           # חוקי המשחק: טיסה, ירי, רמות, חנות
npm run test:server  # השרת האמיתי: חשבונות, קרב בין שני טייסים, תשלום, שמירה
npm run test:browser # דפדפן אמיתי, טלפון ומחשב, עם צילומי מסך ב־shots/
node tools/pilot-bot.mjs 3   # בוט שמשחק 3 דקות ומדווח על האיזון
```

## העלאה לאוויר (Render, חינם)

1. ב־Render בוחרים **New → Blueprint** ומחברים את הריפו הזה. הקובץ `render.yaml` מגדיר הכל.
2. כשמתבקשים, מדביקים ב־`MONGO_URL` את כתובת ה־MongoDB Atlas. אפשר את אותו cluster של Hobile: הנתונים יישמרו במסד נפרד בשם `skyfight`.
3. בתוכנית החינמית השרת נרדם אחרי 15 דקות בלי שחקנים, ומתעורר בכניסה הבאה תוך בערך 50 שניות. בזמן הזה הדף מציג "השרת מתעורר".

## איך זה בנוי

- `src/shared/`: החוקים, שהשרת והדפדפן מריצים אותם בדיוק: מטוסים ומחירים (`planes.js`), האיים (`arena.js`), מודל הטיסה (`flight.js`) וירי וטילים (`combat.js`).
- `src/server/`: Express לחשבונות ולהאנגר, ו־Colyseus לזירה (`rooms/ArenaRoom.js`).
  - **התנועה:** כל טייס מטיס את המטוס שלו על המסך שלו, כדי שהשליטה תהיה מיידית. השרת בודק כל תנוחה מול מה שהמטוס באמת יכול לטוס.
  - **פגיעות ותשלום:** כדורים, טילים, פגיעות, הפלות ותשלום נקבעים רק בשרת.
- `src/client/`: three.js. כל המטוסים, הים, האיים והעננים נבנים בקוד, בלי קבצי מודלים להוריד.
